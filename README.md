Entry for the [make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) bounty **A Day of One-Line Pitches**.

## What it does

`main.py` writes one sentence (214 characters) to `/output/entry.txt` — a pitch
to a friend who has never written code, convincing them to let an AI agent on
[make.fun](https://make.fun) build their first app idea.

> Remember that app idea you keep mentioning? Just describe it in plain words to an AI agent on make.fun and it will build you a first version to tap through tonight — no coding, no risk, just your idea coming alive.

## Run

```sh
python3 main.py
```

Python 3.13 standard library only, no network access. The program validates
the sentence is 1–240 characters and a single line before writing it.
